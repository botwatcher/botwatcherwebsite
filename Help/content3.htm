Cursor Files

Once you have chosen the Cursors area you are shown a listview containing the available categories for the cursors and a list on the right of the screen containing the system cursors you can alter. Each category in the listview is represented by a folder, double click a folder to enter that category. Once a category area has been chosen the listview will show the available cursor files and a folder icon with the name ".."., this icon will take you back up one level to the category section when double clicked.

To change any of the system cursors you can simply drag a cursor from the listview onto any one of the entries in the system cursor list. This will then copy the cursor onto your computer and change the system cursor, which will be reflected in windows immediately.

If you change a system cursor, to an animated cursor and then exit the browser, you need to reboot your computer for the animated system cursor to be installed properly. A dialogue box will tell you this when you exit the browser and also give you the option to reboot your computer. This only applies to animated cursors, non-animated cursors will be installed properly without having to reboot your computer.

If you get tired of your current cursor, and would like to set it back to the system default, select the cursor in the list and then click Use Default.

The schemes group situated above the system cursor list allows you to save out sets of cursor you have selected. If you select Save As in the schemes group you will be prompted for a name for the scheme. You can load back previously saved schemes by selecting their names in the drop down combo box. The schemes presented here are also synchronized with those used in control panel's mouse applet.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Default Cursor
Sets the default system cursor for the selected item in the System Cursors view on the right of the screen.
