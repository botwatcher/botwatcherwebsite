Wave and Midi Files

Once you have chosen the Sounds area you are shown a list-view containing the available categories for the sounds and a list on the right of the screen containing the system application sound events you can alter. Each category in the list-view is represented by a folder, double click a folder to enter that category. Once a category area has been chosen the list-view will show the available files and a folder icon with the name ".."., this icon will take you back up one level to the category section when double clicked.

To change any of the sound events you can simply drag a sound from the list-view onto any one of the entries in the sound event list. This will then copy the sound onto your computer and change the sound event, which will be reflected in windows immediately.

Above the sound event list is the sound file group. This group represents the file for the sound event you have selected in the sound event list. If you would like to here the sound event then select it in the list and click the play button in the sound file group. Here you can also browse for an alternative file or select none to set no sound for the selected event.

The schemes group situated above the sound list allows you to save out sets of sound events you have selected. If you select Save As in the schemes group you will be prompted for a name for the scheme. You can load back previously saved schemes by selecting their names in the drop down combo box. The schemes presented here are also synchronized with those used in the control panel's sound applet.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Browse
Opens a file open dialogue to select a file other than those included with this product as a sound event.

None
Sets the sound associated with the selected Sound Event to nothing.

Other Sound Formats
Many of the discs created with this program contain more than just midi and wav files. Sometimes module files including .mod/.xm/.s3m formats are included for your convenience. These files will not play directly through the browser and require an external program to access them. Plenty of module players are provided on the disc, many of which make file associations with these file types so they can be launched directly from the browser by double clicking them.
