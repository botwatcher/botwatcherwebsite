Cleaning

When installing files onto your computer, it can be quite difficult to remember all the locations files have been moved to. After installing several wallpapers and sounds small hard drives can quickly become full and a clean up required. To ease the burden on users we have included a facility to log all files installed to your computer.

WARNING: All files installed to your computer are logged regardless of their intended use, please be careful when removing files. For example: If you have installed a file as you system wallpaper, and it is currently set, it will still appear in the cleaning list for deletion. If you delete it in the cleaning list, it is obviously no longer available for use as the wallpaper, and no wallpaper will be selected. Deleting a used file can do no fatal damage, it might just undo the changes you have made to your computer.

The cleaning list contains 5 columns in it's list, they are:

Path
The path of the installed file. Where the file actually resided on your hard drive at the time of installation..

Size
The size of the file at the time of installation.

Date Installed
The date the file was installed onto your computer.

Area
The browser area you where in when you installed the file.

Present
Whether the file was still present at the time of updating the list. (The cleaning list is first updated during the loading of the browser or when you press the update button)

Delete File(s)
Delete files will delete and remove all the selected files in the cleaning list.

Remove File(s)
Remove files will remove all the selected files in the cleaning list but not delete them.

Purge
Purge will remove all the files in the list, which are no longer present on your system.

Update
Update will reload the recorded list of files from the system registry.
