Bitmaps and Wallpapers

Once you have chosen the Bitmaps and Wallpapers area you are shown a list-view containing the available categories for the backgrounds and a image view to the right of the application to preview the images in. The list-view and the image preview are separated by a horizontal splitter, which allows you to alter the size of the image view. Each category in the list-view is represented by a folder, double click a folder to enter that category. Once a category has been entered the list-view will show the available files and a folder icon with the name ".."., this icon will take you back up one level to the area section when double clicked.

Through the use of the options mentioned below you can control whether the background image you set will be tiled, stretched or centered (normal), whether the browser will automatically overwrite files and whether thumbnail icons will be created for each of the pictures in the list-view.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Copy to Clipboard
Copy to clipboard will copy the currently displayed image into the Windows Clipboard. You can now enter another program and select paste to use the image in that application.

Set Wallpaper
This will copy the selected bitmap to your windows directory and set it as your current desktop wallpaper. Tile Wallpaper and Stretch Wallpaper effect the display of the wallpaper you install.

Tile Wallpaper
If the Tile Wallpaper option is on when you set a system wallpaper that is smaller than the desktop size, tiling will copy the wallpaper repeatedly across and down the desktop to fill the entire area.

Stretch Wallpaper
If the Stretch Wallpaper option is on when you set a system wallpaper that is smaller or larger than the desktop size, stretching will resize the image to fill the entire desktop, or make the entire image visible within the desktop. Microsoft Plus! Or the Microsoft font-smoothing tool is required for wallpaper stretching.

If neither Tile nor Stretch Wallpaper are selected the wallpaper will be centered on your desktop.

Overwrite Wallpaper
The Overwrite Wallpaper toggle is used to decide whether the browser will prompt or automatically overwrite existing wallpapers on your computer.

Create Thumbnails
Create Thumbnails is used to enable or disable the creation of thumbnails. On a slow computer, or CD-ROM drive, auto creation of thumbnails can take a very long time. Turn this option on and test whether the results are adequate for your needs.
