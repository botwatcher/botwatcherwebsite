AVI Movie Files

Once you have selected the AVI Move Files area you are shown a list-view containing the available categories for the movies and on the right of the area is a preview window in which the AVI movies play. Each category in the list-view is represented by a folder, double click a folder to enter that category. Once a category area has been chosen the list-view will show the available movie files and a folder icon with the name ".."., this icon will take you back up one level to the category section when double clicked.

The selected file is displayed in the preview window . Below this is a group box containing the play, pause, stop, skip etc buttons for the movie and a toggle to flick between full screen and preview mode.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Full Screen
This toggle will control how you preview your AVI video files. When deselected the AVI will be played in the preview window on the right of the screen. If this option is set, the AVI will either be played in a scalable window, or full screen, depending on how your computer is configured.
