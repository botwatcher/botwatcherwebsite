Gif's, Jpeg's and Textures

Once you have selected the Gif's and Jpeg's area you are shown a list-view containing the available categories for the graphics and on the right of the area is a list showing the properties of the selected file. The properties list is will change depending on the format of the file you have selected. For example the information shown in the properties list is different for Jpeg and Gif files. To enter a category, simply double click it's folder.

The selected file is displayed in a centered preview window below the properties list. Below this is a track bar, which allows you to select individual frames from animated gif files. Beside the track bar is a checkbox which will allow you to toggle the animation of the graphic preview.

The textured tab, situated above the list-view will show a tiled version of the selected graphic allowing you to preview the file as a tiled background image.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Background Colour
Allows you to change the colour used behind the jpeg or gif being displayed. This is very useful to see how a transparent image will look on a particularly background colour

Animating
A toggle used to turn the animation preview for Animated Gif's (Gif89a) on or off.
