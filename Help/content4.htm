Screen Savers

When the Screen Savers area is chosen you are presented with a list-view containing a selection of screen savers and directories. Most screen savers shown at the root level all require one single file to operate and do not require installation to run, however some may require installation. These files can be previewed instantly and easily installed. Not all screen savers reside on your computer as a single file though, and many need to be installed. The directories presented in the screen savers list-view represent screen savers that need to be installed. When you enter their directories you double click the screen savers setup program. Once installed you select the refresh button to refresh the screen saver information provided by windows, and select the screen saver from the drop down combo box.

The right side of the application is divided into two groups, "Screen Savers on CD" and "Windows Screen Savers Settings". Screen Savers on CD shows you a running preview of the current screen saver selected in the list-view and two buttons to alter the settings of the screen saver and to launch a full screen preview of the screen saver. The Windows Screen Saver Settings group is used to manipulate screen saver settings in windows. Once a screen saver is installed it can be selected from the drop down combo list or have its setting changed and full screen preview launched. You can set the delay before the screen saver kicks in and also change the screen saver password. When you install a screen saver select refresh to update the screen saver list in the combo box.

Visual Basic Runtime Libraries
Some screen savers require the installation of Visual Basic Runtime (Vbrun) libraries in order for them to work properly. You can install the libraries from the driver's area of the tools and utilities browser.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Set Screen Saver
Set Screen Saver will copy the selected .SCR file to the windows directory and set it as the default System Screen Saver.

Preview (On CD)
This will launch a full screen preview of the .SCR file selected

Settings (On CD)
Opens the settings dialogue of the .SCR file selected

Preview (Windows)
This will launch a full screen preview of the Screen Saver installed in windows.

Settings (Windows)
Opens the settings dialogue of the Screen Saver installed in windows.

Change Password
Changes the password required to exit the system Screen Saver.
