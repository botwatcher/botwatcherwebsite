System Fonts

Once you have selected the System Fonts area you are shown a listview containing the available categories for the fonts and on the right of the area is a panel containing information about the selected font, and a preview window in which the selected font can be viewed. Each category in the listview is represented by a folder, double click a folder to enter that category. Once a category area has been entered the listview will show the available files and a folder icon with the name ".."., this icon will take you back up one level to the category section when double clicked.

When a font is selected the browser will interrogate the font and extract its Font Name, Family Name, Version, Copyright and Trademark information. It will also temporally install the font directly from the CD and give a custom preview in the sample box. You can change the point size and text for previewing fonts.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Install Font
Install font will copy the selected font to your system, and then permanently install it onto your system. Instantly making it available to windows, and almost all running applications.

Auto Preview
This toggle will control how you preview your Font files. When selected the font will be automatically installed, and removed for you if necessary as you select fonts. When not selected the fonts are not installed, and a best match is selected from the fonts installed on your system
