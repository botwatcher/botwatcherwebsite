Icon Files

Once you have chosen the Icons area you are shown a list-view containing the available categories for the icons and a list on the right of the screen containing the system icons you can alter. Each icon category in the list-view is represented by a folder, double click a folder to enter that category. Once a category area has been chosen the list-view will show the available icon files and a folder icon with the name ".."., this icon will take you back up one level to the category section when double clicked.

To change any of the system icons you can simply drag an icon from the list-view onto the one of the entries in the system icon list. This will then copy the icon onto your computer and change the system icon. You can also rename these system icons be selecting one, and then clicking the Rename button.

If the system icons do not change, click on a blank area of the desktop then press the F5 key to refresh the desktop.

If your desktop gets a little messy, and you are finding it hard to navigate your system with the names and icons you have chosen, you can reset the default name be selecting a system icon and clicking the Default button.

The schemes group situated above the system icons list allows you to save out sets of icons and names you have selected. If you select Save As in the schemes group you will be prompted for a name for the scheme. You can load back the saved schemes by selecting their names in the drop down combo box.

Copy File(s)
Copy files will copy all selected files to a destination directory of your choice. You will be presented with a browse for folder dialogue which will allow you to select the destination folder, once selected click on OK to proceed or Cancel to exit.

Default Icon
Sets the default system icon and name for the selected item in the System Icons list on the right of the screen.

Rename Icon
Renames the selected item in the System Icons view on the right of the screen.
